# NorthBridge Dynamic Website

## Run locally

1. Node.js install karein
2. Folder open karein
3. Terminal me run karein:

```bash
npm install
npm start
```

Website open:
http://localhost:3000

Admin panel:
http://localhost:3000/admin

## Free hosting suggestion

Use Render:
- New Web Service
- Connect GitHub repository
- Build Command: npm install
- Start Command: npm start
- Free subdomain example: northbridge.onrender.com
